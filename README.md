# Summative-Assessment---Dashboard-
This project is a Sales Data Dashboard created as part of my Summative Assessment. The dashboard analyzes sales, customers, products, orders, and profitability to provide clear and interactive business insights.
🛠️ Tools Used
Microsoft Excel – Data cleaning and preprocessing
Power BI – Data visualization and dashboard development
DAX – Measures and calculations
📌 Dashboard Pages
1. Executive Dashboard
Provides an overall view of sales performance through key KPIs and visualizations, including:
Profit trends
Top products
Location/region performance
2. Customer Dashboard
Analyzes customer behavior and purchasing patterns, including:
Customer orders
Repeat customers
Customer-wise sales
Customer and product relationship
3. Product dashboard
 Sales by product
Order distribution by product
Sales and profit by product
4.Insights and recommendations
Highlights key findings from the analysis and provides data-driven recommendations based on sales, customer, and product performance
🎯 Objective
The main objective of this project is to transform raw sales data into an interactive Power BI dashboard that helps users understand sales performance, customer behavior, product performance, and key business insights.
